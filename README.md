# NetworkServiceAreas

Sandbox API Repository to describe, develop, document, and test the NetworkServiceAreas Service API(s) within the Sub Project [ConnectivityQualityManagement](https://lf-camaraproject.atlassian.net/wiki/x/hAClB).

* API Repository [wiki page](https://lf-camaraproject.atlassian.net/wiki/x/CwBeNg)

## Scope

* Service API "service-areas" (see APIBacklog.md)
* The API provides the API consumer with the ability to:
  * discover network service areas — geographical areas with coverage consistent with the network profiles and QoS profiles supported there
  * retrieve a specific network service area by its identifier
* Network service areas are used in conjunction with APIs such as DedicatedNetworks, letting the API consumer select where reserved connectivity resources are available
* Describe, develop, document, and test the API
* Started: September 2026
